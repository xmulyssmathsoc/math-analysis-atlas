# 参与共建 · Math Atlas

欢迎贡献准确、易学、可核查的数学内容。推荐先从一个有边界的 Issue / Pull Request 开始。

## 新增概念节点

编辑 `data/curriculum.json`，为新节点填写唯一 `id`、标题、所属阶段（0–4）、主题领域、先修节点 `prerequisites`、准确的概述、LaTeX 核心公式、直觉解释、常见误区和一条启发式问题。`prerequisites` 必须是已有节点 ID，不能构成依赖环；不应要求学习者先掌握更高阶段的节点。

## 新增深度讲义

编辑 `data/lessons.json`，按节点 ID 添加 `goal` / `definition` / `theorem` / `proof`（分步骤数组）/ `worked` / `think`。证明必须列清楚假设、量词、定理适用条件与关键不等式。若写的是直觉解释，请不要标题中声称是“严格证明”。

## 新增练习

编辑 `data/exercises.json`。每题包括唯一 `id`、关联节点 `topic`、难度 `difficulty`（0–4）、题型 `kind`、题干、提示与解析。

- `choice`：提供选项数组，以及从 0 开始的正确选项索引。
- `numeric`：给出可核算的数值答案与必要容差；避免把符号答案硬凑成浮点数。
- `proof`：提供参考证明与逐项 rubric，前端仅记录“完成自评”，不进行自动判对。

每个题目建议附至少一个**典型错误答案的解释**或可审查反例，以供未来错因诊断使用。

## 内容与许可审核

- 新增内容需原创或使用明确允许再利用的材料，并准确标注来源/许可。
- 不上传受版权限制的教材全文、盗版 PDF、课程视频转载或考试泄题。
- 数学符号建议使用 `$...$`（段内）和 `$$...$$`（独立公式）；存储在 JSON 字符串中时，反斜杠要正确转义。
- 提交前运行 `npm run validate` 与 `node --check assets/app.js`。

## 审查清单

- [ ] 先修依赖正确且无环。
- [ ] 公式与记号规范，没有混淆必要/充分条件。
- [ ] 证明每步的条件和推导清楚，极端/边界情况已检查。
- [ ] 题目答案可人工独立验算，提示不直接泄露答案。
- [ ] UI 移动端可用，交互支持键盘操作。
- [ ] 没有提交 API 密钥或个人敏感信息。
