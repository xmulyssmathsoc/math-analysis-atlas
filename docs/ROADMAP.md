# Math Atlas · 发展路线

## v1.0 · 可运行的学习站点（本次交付）

- [x] 五阶段课程目录与 60 个知识点
- [x] 104 条可验证的 DAG 先修关系
- [x] 拖动、缩放、依赖高亮的 SVG 知识图谱
- [x] 15 份重点讲义、46 道五级练习
- [x] 即时客观题反馈、证明题 rubric 自评
- [x] ε–δ 与 ε–N 可交互实验
- [x] 基于先修掌握状态的启发式推荐
- [x] 本地预设引导与可选模型服务端示例
- [x] 学习进度、收藏、答题记录本地持久化
- [x] 结构校验、自动部署 workflow 与文档

## v1.1 · 内容质量优先

- [ ] 每个节点至少补一份完整严谨例证，扩大习题量与解析层次
- [ ] 数学教师/高年级学生同行审校、勘误流程与出处索引
- [ ] 增加反例库、典型错误标签、先修边的人工证据
- [ ] 允许下载或导入学习档案，避免单浏览器数据丢失
- [ ] 改进移动端图谱操作与无障碍支持

## v2.0 · 教学智能化

- [ ] 构建隐私友好的账户同步（用户显式选择）
- [ ] 题目难度和诊断按真实数据校准，不再只靠自标记
- [ ] 数学证明的步骤标注与人工可复核的 AI 反馈
- [ ] 支持根据错因选择针对性习题、间隔复习与掌握度不确定性
- [ ] 教师端课程编排与班级看板，建立权限和隐私治理

## v3.0 · 数学分析开放知识生态

- [ ] 逐步向测度论、泛函分析、复分析、偏微分方程等扩展
- [ ] 为定理与证明提供 machine-readable schema 和出处
- [ ] 与 Lean/Mathlib 等形式化工具选配互通，区分证明验证与 AI 解说
- [ ] 通过内容审核管道接受社区贡献，并形成版本化数学知识图谱

说明：Roadmap 是规划，不代表当前功能已经全部实现。
