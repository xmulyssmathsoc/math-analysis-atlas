# AI 数学教学设计原则

Math Atlas 的目标是引导学习者建立能迁移的数学推理，而不是快速生成答案。

## 教学流程

**定位概念 → 检查先修 → 诊断误区 → 提供最小提示 → 让学生复述或证明 → 复盘下一步。**

具体实践：

1. 每次对话聚焦一个知识节点，并能调取关联的定义、前提、误区与练习。
2. 学习者卡住时，先给最小化提示（例如“把平方差分解”），而非直接给定整个证明。
3. 对开放性证明，区分：量词正确性、适用条件、逻辑有效性、反例可能性、结论是否覆盖全部情形。
4. 当学生明确要求完整推导，给出有条件的严谨解答，而非把拒绝回答当作“苏格拉底式教学”。
5. 学生提出疑问时，优先说明为何选择这个提示；必要时允许学习者切换为完整例题模式。
6. 学习状态仅用于建议下一步，不冒充正式能力评估。

## 本地与模型模式的区别

| 功能 | 本地预设引导 | 配置模型服务端 |
| --- | --- | --- |
| 读取知识点标题、定义与常见误区 | ✅ | ✅ |
| 基于预编写规则提供引导提示 | ✅ | 由模型判断 |
| 分析自由文本中的具体逻辑漏洞 | ❌ | 可能，但仍需核对 |
| 严格证明形式化验证 | ❌ | ❌（需独立符号/形式系统） |
| 多轮自然语言理解 | ❌ | ✅ |
| 服务端保管模型密钥 | 无需密钥 | ✅ |

AI 的教学价值和风险均高度依赖具体实现。研究并不支持“只要有聊天机器人就一定学得更好”的简单结论，因此本项目优先保证内容结构、师生互动设计与数学可核查性。

## 引导示例

**学生**：我不懂 $\lim_{x\to2}x^2=4$ 怎么用 ε–δ 证明。  
**导师**：先把 $|x^2-4|$ 分解。你觉得还需要控制哪一项，才能只用 $|x-2|$ 来保证误差？  
**学生**：我能得到 $|x-2|\cdot|x+2|$，但不知道 $|x+2|$ 怎么办。  
**导师**：可以先增加一个约束 $|x-2|<1$，这样你能为 $|x+2|$ 找到怎样的上界？  
**学生**：小于 5，所以取 $\delta=\min\{1,\varepsilon/5\}$。  
**导师**：很好。接下来请把这一步写成“给定任意 ε>0，取……，若……则……”的完整量词证明。

这个例子中的数学步骤有真实的证明支撑；在线模式依然不能保证输出绝无错误。
